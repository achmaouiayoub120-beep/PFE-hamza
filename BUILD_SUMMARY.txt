================================================================================
                          QUICK START GUIDE
================================================================================

1. INSTALL DEPENDENCIES:
   npm install

2. SET UP DATABASE:
   cp .env.example .env.local
   npx prisma migrate dev --name init

3. START DEVELOPMENT:
   npm run dev
   Open http://localhost:3000

4. DEPLOY TO VERCEL:
   git push origin main
   Connect GitHub repo to Vercel
   Add DATABASE_URL (Neon PostgreSQL)
   Deploy!
